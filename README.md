# 🇮🇳 India Retail Location Intelligence & Expansion Dashboard

An interactive multi-city retail location intelligence dashboard built using **Power BI** and **DAX** to assist strategic site selection and market expansion.

---

## 📊 Project Overview
This project evaluates retail potential across major metropolitan cities in India (**Kolkata, Mumbai, and Bangalore**). It combines spatial analysis, demographic insights, and competitor mapping to help businesses identify high-converting expansion spots.

---

## 🚀 Key Features & Pages
1. **Overview Page:** Multi-city navigation map providing a macro-level view of retail hubs across India.
2. **City Deep-Dive Pages (e.g., Kolkata):** 
   - **KPI Cards:** Top recommended spot (e.g., Shambazar), average potential score, and footfall index.
   - **Geographical Distribution Map:** Visualizing localized retail potential and store clusters.
   - **Market Saturation vs. Opportunity:** Scatter plots evaluating competitor counts against footfall scores.
   - **Detailed Data Tables:** Comprehensive breakdown of top localities (e.g., Rajarhat, Park Street, Salt Lake, Gariahat).

---

## 🛠️ Tech Stack & Tools
- **Visualization & BI:** Power BI
- **Data Modeling:** DAX (Data Analysis Expressions)
- **Spatial Data:** OpenStreetMap / GIS Datasets
